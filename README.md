# 重複行削除ツール（Duplicate Line Remover）

テキストを貼り付けて重複した行を一括で整理・削除できるブラウザ完結型ツールです。  
外部サーバーとの通信は行わず、お使いのパソコンのブラウザ内だけで処理されます。

## こんなときに

- 名簿やメールアドレス、商品コードのリストから重複を取り除いて1つにまとめたいとき
- ログファイルやテキストデータの中で「何が重複していたのか」を抽出・確認したいとき
- 社外秘のデータや個人情報を含むテキストを、外部サーバーに送信せずに整理したいとき

## 主な機能

- **重複行の削除**: 同じ内容の行を1行にまとめ、重複のないきれいな一覧を作成します（初出の順番を維持）。
- **重複行のみ抽出**: 2回以上現れた重複行だけを抜き出し、リストアップします。
- **2ペイン比較**: 左に入力テキスト、右に処理結果を表示するため、元のデータを消さずに見比べることができます。
- **処理オプション**: 空白（スペース）のトリム、英字の大文字・小文字の同一視、空行の扱い、並び替え（昇順・降順）を選べます。
- **元に戻す (Undo)**: 直前の操作状態にワンクリックで戻せます。
- **ファイル連携**: テキストファイルのドラッグ＆ドロップ読み込み（UTF-8 / Shift-JIS 自動判別）や、結果のテキストファイル保存に対応しています。

## 使い方

### ブラウザで使う（かんたん）

1. [重複行削除ツールを開く](https://zero-dev.jp/duplicate-line-remover/) をクリックします（またはダウンロードした `index.html` をブラウザで開きます）。
2. 左側の「入力テキスト」の欄に、整理したいテキストを貼り付けます（または「ファイルを開く」ボタンやドラッグ＆ドロップでテキストファイルを読み込みます）。
3. 必要なら、「処理オプション設定」を開き、トリムや空行の扱いなどを設定します。
4. 「重複削除を実行」ボタンを押します（重複している行だけを調べたいときは「重複行のみ抽出」を押します）。
5. 右側の「処理結果」の欄に、重複が整理されたテキストが表示されます。
6. 「結果をコピー」を押してクリップボードにコピーするか、「保存 (.txt)」を押してファイルとして保存します。

### ダウンロードして使う（パソコンに保存する場合）

1. 本リポジトリのファイルを一括ダウンロードまたはクローンします。
2. Windows をお使いの場合は、フォルダ内の **`ツール起動.bat`** をダブルクリックすると、既定のブラウザで即座に起動します。
3. Mac や Linux の場合は、`index.html` をお好みのブラウザで直接開いてください。インターネット接続がなくても動作します。

## うまくいかないとき

- **重複が消えないように見えるとき**: 行の前後に見えないスペース（空白）が含まれている可能性があります。「処理オプション設定」を開き、「前後の空白をトリムして比較」にチェックを入れて再度お試しください。
- **大文字と小文字が別々の行として残るとき**: 「処理オプション設定」の「大文字・小文字を区別しない」にチェックを入れてください。
- **「重複削除を実行」を押したあと画面が固まる（反応しない）とき**: 行数や文字数が非常に多い超巨大データを処理している可能性があります。処理が完了するまで数秒〜数十秒そのままお待ちいただくか、テキストを小分けにしてお試しください。
- **ファイルが開けないとき**: 対応ファイルはテキスト形式（`.txt`, `.csv`, `.tsv`, `.log` 等）です。WordやExcel（`.xlsx`）、PDFなどのバイナリファイルには対応していません。

## 動作環境

- モダンWebブラウザ（Google Chrome, Microsoft Edge, Mozilla Firefox, Apple Safari）
- インターネット接続は不要です（オフライン環境でも動作します）。

## 制限・注意

- **ファイルサイズ上限**: ブラウザのフリーズを防ぐため、ファイル読み込みは **1ファイルあたり 20MB を上限** としています（5MB を超えるファイルでは読み込み・処理に数秒かかる場合があります）。
- **超巨大データ（行数）の扱い**:
  - 本ツールはお使いのブラウザ上で直接動作するため、**10万行を超えるような超巨大テキストを一括処理する場合、処理中にブラウザが一瞬固まる（応答しなくなる）現象やメモリ消費の増大が発生する可能性があります**。
  - 数十万行規模のテキストを処理する場合は、あらかじめ数万行単位に分割して処理することをおすすめします。
- **文字コード**: UTF-8 および Shift-JIS（CP932）の自動判別に対応しています（その他の特殊な文字コードでは文字化けが発生することがあります）。

## 外部通信

- **外部通信は行いません**。
  入力されたテキストやファイルが外部のサーバーに送信されることはありません。Content Security Policy（CSP）により、外部通信を技術的にも遮断しています。
